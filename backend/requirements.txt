# Raster / overlay generation.
#
# numpy + pillow do the analysis. `rasterio` is present for ONE reason: reading
# the ESA WorldCover GeoTIFF as a windowed COG in scripts/fetch_landcover.py.
# Its wheels bundle GDAL, which is why no Homebrew GDAL is needed on this host
# -- that was previously logged as an untried option and is now settled.
#
# Everything else stays pure numpy + pillow. The overlay maths needs no GDAL, and
# adding it to the critical path would have made a Homebrew install a hard
# dependency for no benefit.

pillow>=10.0

# scipy is used for exactly one thing: `scipy.sparse.csgraph.dijkstra`, for the
# least-cost-path ventilation corridors. A corridor is the cheapest through-route across
# a cost surface, and a hand-rolled priority queue in numpy would be slower and
# less trustworthy than the reference implementation. Nothing else in the project
# imports scipy, so this is a narrow, replaceable dependency rather than a
# numerical stack.
#
# Floor, not ceiling. An earlier version pinned `<1.14` to dodge a macOS dyld
# failure in 1.15.3's compiled `_propack` extension on Python 3.10. That ceiling
# is wrong everywhere else: 1.13.1 has no wheel for Python 3.14 (the build from
# source fails), so it made the corridors uninstallable on the Windows/3.14 host.
# 1.16.1 is the first release with a cp314 wheel (1.16.0 and earlier have none);
# 1.18.1 is the version verified here.
# If the macOS failure ever returns, pin that machine, not everyone.
scipy>=1.16.1
