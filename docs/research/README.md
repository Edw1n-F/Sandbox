# Research chapters

The five-chapter research write-up behind the heat, wind and drainage design.
Every rule the sandbox applies is traceable to a citation in these files; they
are the "why" behind `STATUS.md`'s "what".

They are research records, not build instructions. For how to run the project
see [`README.md`](../../README.md); for the current state see
[`STATUS.md`](../../STATUS.md).

The organising finding, common to all five: heat, wind and drainage are **not
three features but one geometry read three ways**. A designer controls two
comfort variables — maximise wind speed, minimise solar radiation (Ng & Cheng,
*Building and Environment* 44 (2009) 1478–1488) — and both are functions of the
same height, spacing, orientation, podium coverage and ground permeability.
